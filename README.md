# Java Engineering Bootcamp Book (Multi-Page HTML)

This repository contains a complete multi-page Java book for developers who already know Python, JavaScript, and R.

The content is written in English and includes:

- Heavy theory and practical tutorials
- Modern Java coverage (Java 17-25 era features and practices)
- Backend, frontend, desktop, and mobile tracks
- Architecture and design theory
- Dedicated install and configuration blueprint (toolchain, profiles, infra)
- Case-based snippet handbook for daily engineering work
- Light and dark theme toggle (persisted in browser storage)

## Open the Book

Open `index.html` in your browser.

## Chapters

1. `index.html` - Start Here (book map and outcomes)
2. `install-config.html` - Complete install and configuration blueprint
3. `core-syntax.html` - Core syntax, OOP, and type modeling
4. `modern-java.html` - Modern Java patterns and language features
5. `jvm-and-performance.html` - JVM internals and performance engineering
6. `backend-enterprise.html` - Backend architecture and production APIs
7. `frontend-java.html` - Frontend strategies with Java
8. `desktop-javafx.html` - Desktop engineering with JavaFX
9. `mobile-android.html` - Mobile development with Java and Android
10. `architecture-design.html` - Architecture and software design theory
11. `testing-devops.html` - Testing strategy, CI/CD, and operations
12. `tutorials.html` - Guided hands-on tutorials
13. `handbook.html` - Case-based code snippet handbook
14. `capstone-roadmap.html` - 12-week capstone execution plan
