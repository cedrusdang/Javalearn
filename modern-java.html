Write Java as of 2026, Not 2016

Modern Java emphasizes expressiveness with records, pattern matching, sealed hierarchies, virtual threads, structured concurrency, and clearer APIs. The fastest way to level up is replacing legacy ceremony with intentional modeling.

2.1 Records for Data-Centric Modeling

public record Trade(String symbol, int quantity, double price) {
    public Trade {
        if (quantity <= 0) throw new IllegalArgumentException("quantity must be positive");
        if (price <= 0) throw new IllegalArgumentException("price must be positive");
    }

    public double notional() {
        return quantity * price;
    }
}

Records remove boilerplate while preserving explicit domain constraints.

2.2 Sealed Types + Pattern Matching

sealed interface PaymentResult permits Success, Declined, FraudFlagged {}
record Success(String transactionId) implements PaymentResult {}
record Declined(String reason) implements PaymentResult {}
record FraudFlagged(String rule) implements PaymentResult {}

String render(PaymentResult result) {
    return switch (result) {
        case Success s -> "Approved: " + s.transactionId();
        case Declined d -> "Declined: " + d.reason();
        case FraudFlagged f -> "Investigate: " + f.rule();
    };
}

This gives exhaustive handling at compile-time, similar to algebraic data types.

2.3 Virtual Threads (Project Loom)

try (var executor = java.util.concurrent.Executors.newVirtualThreadPerTaskExecutor()) {
    List<Future<String>> tasks = IntStream.range(0, 1000)
        .mapToObj(i -> executor.submit(() -> fetchRemoteData(i)))
        .toList();

    for (Future<String> task : tasks) {
        System.out.println(task.get());
    }
}

For IO-heavy workloads, virtual threads simplify concurrency without reactive complexity.

2.4 Scoped Values and Structured Concurrency

  • Scoped values are safer than thread-locals for request context.
  • Structured concurrency aligns child-task lifecycle with request lifecycle.
  • Together, they reduce leak-prone async code.

2.5 API Upgrades You Should Use

  • HttpClient for HTTP calls with HTTP/2 support.
  • Files.readString / writeString for concise file operations.
  • Stream.toList() for immutable collection pipelines.
  • Optional.orElseThrow() for explicit failure behavior.

Migration Checklist

  1. Replace mutable DTOs with records where suitable.
  2. Replace giant if-else trees with sealed + switch pattern matching.
  3. Benchmark virtual threads for IO services before adopting reactive stacks.
  4. Enforce modern style in code reviews.
