Tutorial Pathways

Follow these in sequence. Each tutorial includes objective, constraints, implementation steps, and extension tasks. Build each project in a dedicated repository and tag milestones.

Tutorial A: CLI Data Transformer (2-3 hours)

  1. Input CSV, output JSON summary grouped by category.
  2. Model records and parser abstraction.
  3. Implement stream transformations and validation errors.
  4. Add unit tests for malformed lines and edge cases.
record SalesRow(String category, int units, double price) {}

Map<String, Double> totalByCategory = rows.stream()
    .collect(Collectors.groupingBy(SalesRow::category,
        Collectors.summingDouble(r -> r.units() * r.price())));

Tutorial B: Spring Boot Order API (1 day)

  1. Create endpoint POST /orders and GET /orders/{id}.
  2. Use DTO validation and service layer separation.
  3. Persist with PostgreSQL and migration scripts.
  4. Add integration tests with Testcontainers.

Tutorial C: JavaFX Ops Dashboard (1 day)

  1. Render system events table with filters.
  2. Background polling via scheduled executor.
  3. Charting for event rate trends.
  4. Package desktop installer using jpackage.

Tutorial D: Android Profile App (1-2 days)

  1. List + details screen with repository abstraction.
  2. Offline cache via Room database.
  3. Retry strategy for failed network requests.
  4. UI tests for primary flows.

Tutorial E: End-to-End Distributed Workflow (2 days)

  1. Order service publishes event to queue.
  2. Billing service consumes event and updates state.
  3. Use outbox and idempotent consumer logic.
  4. Add observability traces and chaos testing scenarios.

Bootcamp rule: no tutorial is done unless you can explain trade-offs and failure modes.
