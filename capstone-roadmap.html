Capstone: Omni-Channel Commerce Platform

Build one product with backend APIs, admin web UI, desktop operations console, and Android client. This project proves platform versatility and architecture maturity.

12-Week Curriculum

  1. Week 1-2: Domain model, coding standards, architecture decision records.
  2. Week 3-4: Core backend services + relational persistence + tests.
  3. Week 5: Messaging, outbox, eventual consistency workflows.
  4. Week 6: Java web UI (admin dashboard) and role-based auth.
  5. Week 7: JavaFX desktop console for operations monitoring.
  6. Week 8: Android app MVP with offline cache and sync policy.
  7. Week 9: End-to-end observability and chaos scenarios.
  8. Week 10: Performance tuning and resilience hardening.
  9. Week 11: Security review, threat model, compliance checklist.
  10. Week 12: Demo day, postmortem, and production-readiness review.

Deliverables

  • Architecture diagram set and ADRs.
  • Production-quality source code and automated pipelines.
  • Runbook for operations and incident response.
  • Benchmark and test evidence tied to SLO targets.

Evaluation Rubric

Correctness

Business invariants protected under edge cases.

Reliability

Service survives partial failures and dependency outages.

Maintainability

Clear boundaries, naming, and test structure.

Operations

Actionable telemetry and safe deployment process.

Instructor Advice

Do not chase feature count. Build fewer features with hard quality guarantees. This is how engineers become trusted in production environments.
