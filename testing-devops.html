Serious Teams Treat Delivery as an Engineering System

Testing is not a QA phase. It is a design feedback loop from unit level to production telemetry. DevOps is not tooling only. It is operational responsibility embedded in development.

9.1 Testing Pyramid for Java Systems

  • Unit tests: deterministic domain behavior (JUnit 5 + AssertJ).
  • Integration tests: infrastructure contract checks (Testcontainers).
  • API contract tests: consumer/provider alignment.
  • End-to-end smoke tests: core user journey confidence.
@Test
void shouldComputeOrderTotal() {
    var order = Order.create("cust-1", List.of(new OrderLine("p1", 2, 500)));
    assertThat(order.totalCents()).isEqualTo(1000);
}

9.2 Integration Test with Testcontainers

@Container
static PostgreSQLContainer<?> postgres = new PostgreSQLContainer<>("postgres:16");

@Test
void shouldPersistOrder() {
    OrderRepository repo = new JdbcOrderRepository(postgres.getJdbcUrl(), postgres.getUsername(), postgres.getPassword());
    repo.save(Order.create("c-11", List.of(new OrderLine("a", 1, 2200))));
    assertThat(repo.findAll()).hasSize(1);
}

9.3 CI/CD Pipeline Standard

  1. Static checks (format, lint, SAST, dependency vulnerabilities).
  2. Unit + integration tests with coverage threshold policy.
  3. Container image build and signing.
  4. Progressive deployment: canary or blue/green.
  5. Auto rollback on SLO breach.

9.4 Observability and Incident Readiness

  • Use OpenTelemetry for traces and metrics.
  • Log with request IDs and domain identifiers.
  • Track golden signals: latency, traffic, errors, saturation.
  • Run game days for failure simulation.
