Android: Java Still Matters

Even with Kotlin growth, Java remains critical in Android legacy codebases, SDK integrations, and mixed-language apps. As a Java engineer, you can deliver robust Android systems by mastering architecture and lifecycle discipline.

7.1 Mobile Architecture (Java Edition)

  • Presentation: Activities/Fragments + ViewModel.
  • Domain: use-cases and business services.
  • Data: repository pattern with local + remote sources.
  • Async: coroutines in Kotlin modules or Java executors/reactive wrappers.

7.2 Network + Repository Example

public final class ProfileRepository {
    private final ProfileApi api;
    private final Executor ioExecutor;

    public ProfileRepository(ProfileApi api, Executor ioExecutor) {
        this.api = api;
        this.ioExecutor = ioExecutor;
    }

    public void loadProfile(String userId, Consumer<Profile> onSuccess, Consumer<Throwable> onError) {
        ioExecutor.execute(() -> {
            try {
                Profile profile = api.fetchProfile(userId);
                onSuccess.accept(profile);
            } catch (Throwable t) {
                onError.accept(t);
            }
        });
    }
}

7.3 Lifecycle and State Rules

  1. No business logic in Activities.
  2. Handle offline-first UX for unstable networks.
  3. Use background-safe scheduling for sync jobs.
  4. Guard every external call with timeouts and retries.

7.4 Security on Mobile

  • Store secrets using Android Keystore.
  • Use certificate pinning for sensitive APIs.
  • Never trust client-side authorization checks alone.
  • Audit SDK permissions and data exfiltration risks.
